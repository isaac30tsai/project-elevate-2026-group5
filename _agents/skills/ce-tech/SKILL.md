# Google Cloud CE Technical Excellence Skill

## Overview
Empowers Customer Engineers (CEs) and Solution Architects to rapidly validate enterprise agentic patterns on Google Cloud.

1. **Architecture Blueprint Validation**:
   - Compares customer agent architectures against Project Elevate reference baselines.
   - Evaluates Dual-Agent Producer-Critic loops, FastMCP protocol integration, and CMEK envelope encryption.
2. **Customer Demonstration Playbooks**:
   - Executes live end-to-end multi-turn demonstrations across Gemini Enterprise front doors, WorkWeek HCM, and ServiceImmediately ITSM.
3. **Preflight Environment Readiness**:
   - Runs `bash scripts/preflight_check.sh` to certify IAM roles, KMS keyrings, and quota availability prior to executive briefings.
